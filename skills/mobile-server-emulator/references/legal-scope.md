# 合规与授权范围

## 允许

- **已停服游戏 preservation**：官方已关闭服务器、仅用于个人/小范围研究与存档。
- **自有 App / 靶场**：你拥有源码或书面授权的目标。
- **授权安全研究**：渗透测试合同、CTF、课程实验范围内。
- **学习公开项目**：阅读 GitHub 上标注 educational/preservation 的开源 server emulator，理解其架构而非直接用于运营中的游戏。

## 禁止

- 针对**仍在运营**的商业手游搭建未授权私服。
- 伪造充值、无限货币、破坏其他玩家体验或分发改包牟利。
- 绕过 DRM/反作弊以在官方服务器上作弊。
- 在未授权设备上分析他人 App 并公开敏感数据。

## Agent 拒绝话术

当任务明显属于禁止范围时，明确拒绝并说明原因，可引导到：

- 合法方向：UI 自动化测试（`game-automation-scripting`）
- 正规联机：Unity Multiplayer Services / 自建游戏服务端

## 执行前确认（内部 checklist）

- [ ] 目标游戏是否已停服或是否为你自有/授权目标？
- [ ] 是否仅本地或小范围 preservation，不涉及公开运营？
- [ ] 是否已排除伪造充值与破坏他人体验的目的？
